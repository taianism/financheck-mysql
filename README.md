# FinanCheck

## Sobre o projeto

O FinanCheck é um projero acadêmico desenvolvido para a disciplina de Banco de Dados.

Seu objetivo é modelar e implementar um banco de dados relacional para auxiliar no gerenciamento financeiro pessoal. 

## Funcionalidade 

O banco de dados permite:

- Cadastro de usuário;
- Cadastro de categorias de receitas e despesas;
- Registro de receitas;
- Controle de metas financeiras.

## Tecnologias utilizadas 

- MySQL 8
- SQL (DDL)
- MySQL Workbench

## Estrutura do projeto 

O projeto está organizado da seguinte forma:

```text
financheck-mysql
|
├── docs/
│
├── sql/
│   └── ddl.sql
│
└── README.md
```
## Como utilizar 

Abra  o Mysql Workbench e conecte-se ao servidor MySQL.

Em seguida , abra o arquivo `sql/ddl.sql` e execute todo o script.

Ao final da execução, será criado o banco de dados `financheck`, justamente com suas tabelas, relacionamentos e índices.
